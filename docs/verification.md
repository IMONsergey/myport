# Проверка третьей версии — 15 октября 2026

- 21 страница, 16 уникальных проектов, 734 локальные ссылки и 183 изображения проходят `npm run check`.
- `npm run build` и синтаксическая проверка трёх JS-модулей проходят. Lenis 1.3.23 закреплён lock-файлом; сборка копирует его в локальные static assets.
- В desktop Chrome проверены открытие/закрытие шоурила, controls и воспроизведение, Escape, возврат фокуса, блокировка/возврат прокрутки, меню, активная услуга, смена sticky текстов, параллакс и уменьшение заголовка до scale(.4).
- В iframe 390 × 844 проверены меню с портретом, переход Works, фильтр «Брендинг» (4 работы), открытие Serenity Aviation, загрузка обложки, контактная форма и отсутствие горизонтального overflow.
- Движение параллакса подтверждено изменением translateY от −3.996 до 17.902 px при scale1.25.
- В этой среде `getContext('webgl2')` возвращает null. Проверен Canvas 2D renderer: кадры hero меняются (506 → 758 → 1993). При паузе тело получает motion-paused, видео paused=true, кнопка меняется на «Включить анимацию». После включения движение возобновляется.
- Вторая сцена vision достигла progress1, первый текст opacity0; положение закрепления проверено. Найден и исправлен дефект незавершённого раскрытия первого текста при sticky.
- Проверены ошибки консоли: сообщений приложения нет; browser metadata errors приходят из chrome-extension, вне сайта.
- Письма не отправлялись. Форма по-прежнему открывает почтовый клиент; данные не уходят в сторонний backend.

Ограничения проверки: GPU WebGL2 не доступен в проверочном браузере, а референс в нём теряет shader-фон hero. Проверка изображений и поведения проводилась по остальным доступным сценам и опубликованным параметрам компонентов. Физический touch-девайс и системное изменение prefers-reduced-motion не эмулировались; для движения проверен пользовательский переключатель, для touch обработчик не сбрасывает выбор на pointerleave.

Реальные проекты и авторские кредиты сохранены. Six Senses остаётся с типографической обложкой и ссылкой на оригинальный кейс, поскольку оригинальная галерея ранее была недоступна.
