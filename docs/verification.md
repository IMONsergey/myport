# Проверка второй версии — 15 октября 2026

- 21 статическая страница, 16 уникальных проектов.
- Сборка без npm-зависимостей. Проверены локальные ссылки, изображения, responsive srcset, H1, описания и JSON-LD.
- В браузере проверены главная, каталог, кейс Avito, контакты, меню; ширины 390, 768 и настольная 1363 CSS px.
- Каталог сопоставлен с Uncoded в одном изображении, включая отдельное сравнение типографики. Устранено смещение таблицы на 53 px.
- Фильтр «Брендинг» показывает 4 работы, состояние сохраняется в URL.
- Меню открывается, закрывается по Escape, возвращает фокус. Мобильная ссылка Works ведёт в каталог с 16 проектами.
- Переключение направлений меняет описание и фон. Кнопка паузы останавливает видео и движение резервного фона; её позиция больше не зависит от трансформации заголовка.
- В форме проверены подписи, валидность полей, выбор бюджета. Копирование почты работает. Реальное письмо не отправлялось: форма открывает локальный почтовый клиент.
- Ошибок приложения в журнале не найдено; сообщения browser metadata исходят из расширения проверочного браузера.
- Снимки и история исправлений: `design-qa.md`, `docs/qa/`.

WebGL-ветка не отрисовывается в данном браузере; проверен резервный фон с CSS-движением и видео. Проверка точного движения WebGL на физическом устройстве остаётся дополнительной проверкой. Галерея Six Senses по-прежнему недоступна на Dprofile: сохранены типографическая обложка и ссылка на оригинал. Метрики и отзывы не выдумывались.
