# Otcheskov.Digital — портфолио

Личное портфолио Сергея Отческова, архитектора брендов и цифровых систем.

**Сайт:** https://imonsergey.github.io/myport/
**Исходный код:** https://github.com/IMONsergey/myport

## Состав

- Главная — оригинальная типографическая сцена, четыре флагманских проекта, полный индекс, подход, направления работы, авторский блок.
- Works — избранные проекты, каталог всех 16 работ и фильтры по направлениям.
- 16 кейсов — индивидуальный акцент, контекст, подход, набор решений, адаптивная галерея, просмотр оригинальных изображений, источники и релевантные проекты.
- About — специализация, формат участия в проектах и примеры.
- Contact — email, Telegram и форма подготовки письма.
- 404, sitemap.xml, robots.txt, отдельные Open Graph-карточки.

Все изображения проектов хранятся локально, без зависимости от сторонних CDN. В кейсах APCOSYS и DEBT TECH присутствуют снимки опубликованных сайтов. Six Senses отмечен как архивный, поскольку галерея первоисточника пока не перенесена.

## Локальная разработка

Node.js 20 или новее.

```bash
npm ci
npm run dev
```

Локальный адрес: `http://localhost:4173`.

Для сборки под GitHub Pages:

```bash
BASE_PATH=/myport/ SITE_URL=https://imonsergey.github.io/myport npm run build
BASE_PATH=/myport/ npm run check
```

GitHub Actions публикует содержимое `dist/` автоматически при изменениях ветки `main`.

## Принципы контента

Не указывать неподтверждённые показатели, даты или персональные роли. Для командных проектов сохранять существующее авторство I’MON, BAEV и других участников. Редакционные тексты описывают публично демонстрируемые решения, а не предполагаемые бизнес-результаты.

Внешние ссылки могут блокировать автоматические проверки. Неполученный HTTP 200 не означает, что страница действительно недоступна в браузере.

## Медиа и лицензирование

В публичной версии используются изображения проектов из портфолио. Декоративные видео и фоны, ранее импортированные из референса Uncoded, удалены. Шрифты — локальные с лицензиями OFL (`docs/licenses/`).

Форма обратной связи честно сообщает, что открывает почтовый клиент, а не отправляет данные на сервер. Для прямого обращения доступны `cdo@imon.agency` и Telegram.

## Проверки

```bash
npm run build
npm run check
node --check src/editorial.js
```

Перед публикацией проверять визуальную целостность desktop/mobile, элементы взаимодействия и отсутствие переполнения на узких экранах. Результаты аудитов хранятся в `docs/`.
