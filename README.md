# Сергей Отческов — портфолио

Полный сайт архитектора брендов и цифровых систем: главная, каталог с фильтрами, 16 страниц проектов, об авторе, контакты и 404.

**Сайт:** https://sergey-otcheskov-portfolio.imonsergeii.chatgpt.site

## Запуск

Нужен Node.js 20 или новее. Зависимостей npm нет.

```sh
npm run dev
```

Открыть `http://localhost:4173`. Для сборки и проверки:

```sh
npm run build
npm run check
```

`dist/` — готовый статический сайт. Можно разместить на любом статическом хостинге. Для публикации в подпапке:

```sh
BASE_PATH=/myport/ SITE_URL=https://imonsergey.github.io/myport npm run build
BASE_PATH=/myport/ npm run check
```

## Что где менять

- `content/projects.json` — проекты, тексты, категории, изображения, ссылки и авторство.
- `content/media-sources.json` — источники оригинальных материалов.
- `scripts/build.mjs` — шаблоны страниц, SEO, sitemap и структура.
- `src/site.css` — адаптивный дизайн.
- `src/site.js` — меню, фильтры, копирование почты, кнопка «Наверх».
- `public/media/` — локальные оптимизированные изображения WebP и варианты 800 px.
- `public/fonts/` — локальные шрифты Golos Text и Cormorant Garamond с лицензиями OFL.

Фильтры сохраняются в URL. Меню использует нативный `dialog` с клавиатурным управлением. Контакты ведут в Telegram и почтовый клиент; серверная форма не требуется. Контент доступен без JavaScript, предусмотрены видимый фокус и `prefers-reduced-motion`.

## Контент

Включены 7 работ Dprofile, дополнительные проекты I’MON, APCOSYS и DEBT TECH. У командных проектов сохранено указание I’MON; у Avito — BAEV / I’MON. Не добавлялись неподтверждённые показатели или персональные роли.

Dprofile находился на техническом обслуживании при сборке. Поэтому Six Senses включён как типографическая карточка и страница со ссылкой на исходный кейс; оригинальная галерея этого проекта пока недоступна. Даты публикаций Dprofile не выдаются за годы выполнения проектов.

Визуальное направление вдохновлено Uncoded: редакционная типографика, свободная композиция, крупные изображения. Код, тексты и структура созданы для личного портфолио.

`docs/portfolio-direction.md` сохраняет исходное исследование. Текущее состояние описано здесь и в `docs/verification.md`.
